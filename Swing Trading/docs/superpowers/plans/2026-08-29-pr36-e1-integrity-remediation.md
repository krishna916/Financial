## Global Constraints

- Primary event window remains `2023-08-01` through `2026-06-30` inclusive.
- Source-data cutoff remains `2026-08-25`.
- Temporal halves remain `2023-08-01..2025-01-14` and `2025-01-15..2026-06-30`.
- PIT universe remains Nifty 500 on `Event_Public_Date`.
- Timely-result rule remains Q1/Q2/Q3 <=45 calendar days and final fiscal quarter <=60 calendar days.
- Reporting-basis priority remains complete comparable **consolidated** SUE chain first, otherwise complete comparable **standalone** chain.
- SUE remains `D[t] = EPS[t] - EPS[t-4]`, standardized against exactly `D[t-1]..D[t-8]` with sample SD `ddof=1`.
- Cohort boundaries remain unchanged: `>=1.0`, `[0.5,1.0)`, `(-0.5,0.5)`, `(-1.0,-0.5]`, `<=-1.0`.
- Entry remains the immediate next **canonical market session** Open; missing stock Open on that exact session cancels the observation.
- Hold remains 40 complete trading sessions with exit on the following canonical-session Open, unless a later distinct quarterly result triggers the frozen early-exit rule.
- Friction remains 0.40% / 0.60% / 0.80% round-trip.
- Technical EPS coverage threshold remains >=95% using only formal primary-window `Technical_EPS_Candidate` observations.
- Cross-exchange EPS tolerance remains `abs(a-b) <= 0.01 OR abs(a-b)/max(abs(a),abs(b)) <= 0.005`; for both values exactly zero, relative difference is zero.
- Total cohort insufficiency remains `<300` positive/neutral/negative; temporal insufficiency remains `<100` positive observations in either half.
- `INVALID_RESEARCH_RUN` > `INSUFFICIENT_EVIDENCE` > `PASS/FAIL` precedence remains frozen.
- No momentum, RS, SMA, regime, volume, gap, sector, stop, target, alternate holding-period, SUE-threshold, or history-length rescue is allowed.
- Do not modify V3/R1/M1 code or evidence.

def eps_values_match(a: float, b: float) -> bool:
